# AI Vacancy Analyzer

Учебное веб-приложение для разбора текста вакансий. Пользователь вставляет описание вакансии, нажимает «Проанализировать» и получает четыре блока:

- Ключевые требования
- Технологии
- Управленческие компетенции
- Требуемый опыт

Внешние AI API не используются: анализ выполняется простой демонстрационной логикой на клиенте (поиск ключевых слов, технологий и формулировок об опыте).

## Стек

- [Vite](https://vite.dev/)
- React 19 + TypeScript

## Требования

- Node.js 20+ (рекомендуется LTS)
- npm 10+

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

## Другие команды

```bash
# Проверка TypeScript и production-сборка
npm run build

# Предпросмотр собранного приложения
npm run preview

# Линтер
npm run lint
```

## Как пользоваться

1. Вставьте текст вакансии в большое поле (или нажмите «Подставить пример»).
2. Нажмите «Проанализировать».
3. Изучите четыре блока результатов под формой.

## Структура

```
src/
  analyzer.ts   # демонстрационная логика разбора
  App.tsx       # UI приложения
  App.css       # стили интерфейса
  index.css     # глобальные стили и тема
```
